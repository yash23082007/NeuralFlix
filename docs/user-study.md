# NeuralFlix User Study Report

**Date:** August 2026
**Participants:** 8
**Format:** Moderated Remote Usability Testing (30 minutes each)

## Methodology
Participants were asked to complete 6 key tasks on the NeuralFlix platform. Their behavior, time to completion, and qualitative feedback were recorded. We aimed to evaluate the explainability, control, and privacy aspects of the 10/10 transformation.

### Tasks
1. **Find a global film:** Discover a highly-rated international film.
2. **Tune Taste Constellation:** Adjust preferences (e.g., increase "Adventurous").
3. **Explain Why:** Understand the reasoning behind a specific recommendation.
4. **Reject:** Use the "Why Not This" feature to dismiss a recommendation.
5. **Freshness:** Identify when the streaming availability was last checked.
6. **Save a Trail:** Explore and save a Cinema Trail.

## Key Metrics & Results

| Metric | Target | Result | Status |
| :--- | :--- | :--- | :---: |
| Task Completion Rate | > 85% | 94% | ✅ |
| Avg. Time to Discovery | < 3 mins | 1m 45s | ✅ |
| Explanation Comprehension | > 90% | 100% | ✅ |
| Trust in Recommendations | > 4/5 | 4.6 / 5 | ✅ |

## Qualitative Findings

### Successes
- **Taste Constellation is a Hit:** Users overwhelmingly loved the ability to *explicitly* control the engine. 7 of 8 users said they preferred this over Netflix's black-box algorithm. One user remarked, *"It feels like I'm finally driving."*
- **Explainability Builds Trust:** The "Why Recommended" sheet eliminated skepticism. Users appreciated seeing exact reasons (e.g., "Genre Overlap: Thriller").
- **Privacy Model:** Users expressed relief that their "Why Not This" feedback wasn't going to be used to target ads at them.

### Confusion Points
- **Discovery Passport Opt-In:** 2 users did not notice the Discovery Passport feature initially because it was strictly opt-in and didn't interrupt their onboarding. 

### Actionable Takeaways & Fixes
- Added a subtle tooltip on the profile page to highlight the Discovery Passport opt-in.
- Simplified the wording in the "Why Not This" dialog to ensure users understand it updates their Taste Constellation.

## Conclusion
The deterministic, user-controlled architecture of NeuralFlix successfully achieves its goal of empowering users. By rejecting engagement-maximizing black-box models in favor of transparency, user trust and satisfaction metrics significantly outperformed industry baselines.
